# Based on deep learning YOLOv8 drug recognition detection system (YOLOv8+Y)

## Body

Based on the YOLOv8 deep learning algorithm, this project has developed a drug recognition and detection system. The goal is to achieve automatic recognition and classification of eight different drugs through computer vision technology. The drugs targeted in the system include Cipro 500, Ibuprofen 600 mg, Ibuprofen Cold 400-60, Xyzall 5mg, and four color-coded drugs (blue, pink, red, and white). Through the advanced real-time target detection algorithm of YOLOv8, the system can quickly and accurately recognize drug types. This provides an efficient and reliable solution for drug recognition in the medical health field. Not only can the system identify the specific name and specifications of drugs, but it can also recognize drug classification based on color, demonstrating strong practicality and adaptability. Against the backdrop of frequent medical errors, this technology is expected to significantly reduce medication confusion-related medical accidents, improve medication safety and service quality.
